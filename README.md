# Portfolio Personal

¡Bienvenidos a mi portfolio!

Este sitio fue desarrollado para mostrar mis proyectos, habilidades y experiencia como desarrolladora web. La página está diseñada con HTML y CSS, y es completamente responsiva para adaptarse a dispositivos móbiles.

## Secciones Principales

- **Home**: Presentación personal y mini biografía.
- **Sobre mí**: Breve descripción de mi formación, experiencia e intereses.
- **Habilidades**: Muestra mis diferentes "skills", desde el manejo de distintos lenguajes hasta herramientas de gestión de proyectos.
- **Proyectos**: Sección donde presento algunos proyectos personales y académicos.
- **Contacto**: Formulario para enviarme un mensaje mediante formulario o para contactarme por WhatsApp.

## Características destacadas

- Diseño responsivo adaptado a dispositivos móviles.
- Animaciones suaves para mejorar la experiencia de usuario.
- Código organizado y estructurado por secciones.
