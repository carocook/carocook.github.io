Proyectos

Rimberio Garage

Sistema de gestión para estacionamientos, desarrollado en C# con arquitectura en capas. Manejo de registros mediante XML y diseñado para su implementación en entornos Windows como una aplicación de escritorio.

Climatécnica

Aplicación de escritorio desarrollada en C# y SQL Server para la gestión de una empresa de venta de calefactores. Implementa principios de POO como herencia y composición para la administración de productos y clientes.

Lubricentro Tito

Aplicación de gestión para un lubricentro, desarrollada en C# con una arquitectura basada en herencia y polimorfismo. Diseñada para su uso en sistemas Windows, permitiendo una administración eficiente de servicios y clientes.

Sky Escape: Meteorite Dodger

Videojuego desarrollado en Python con Pygame, donde el jugador debe esquivar meteoritos y administrar sus vidas mientras avanza en la partida. Implementación de sprites, lógica de colisiones y gestión modular del código.
